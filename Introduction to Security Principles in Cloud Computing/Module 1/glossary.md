# Module 1: Glossary Terms

## Terms and Definitions from Course 1, Module 1

1\. Bucket: A virtual container that holds objects

2\. Cloud computing: The practice of using on-demand computing resources as services hosted over the internet

3\. Cloud cybersecurity: The practice of ensuring the confidentiality, integrity, and availability of cloud-based data, applications, and infrastructure by preventing unauthorized access or criminal exploitation

4\. Cloud data storage: A solution that enables organizations to keep, access, and maintain digital data on off-site, cloud-based storage devices

5\. Compute: Computation performed by a physical computer in a remote environment

6\. Container: A software package that holds only the components necessary to execute a particular application

7\. Data center: A physical building that stores servers, computer systems, and associated components

8\. Digital transformation: When an organization modernizes their applications, services, and customer relationships by using new technologies

9\. Ephemerality: The concept that things only exist for a short amount of time

10\. Failure domain: A resource that can fail without impacting the availability of data

11\. Hybrid cloud: A cloud model that combines public and private models, so organizations can enjoy both cloud services, and the control features of on-premises cloud models

12\. Hypervisor: The abstraction layer that sits between the physical computer and the virtual machine

13\. Immutability: The concept of being unable to change an object after it’s created and assigned a value

14\. Instance: A server resource that runs workloads in the cloud

15\. Latency: The time it takes for data to travel from one location to another

16\. Multicloud: A strategy of using more than one cloud service provider

17\. Multi-tenant environment: An environment in which cloud infrastructure and resources are shared among users

18\. On-premises: Information technology infrastructure that’s physically located in an organization’s own data center or office

19\. Private cloud: A cloud model in which all cloud resources are dedicated to a single user or organization, and are created, managed, and owned within on-premises data centers

20\. Public cloud: A cloud model that delivers computing, storage, and network resources through the internet, allowing users to share on-demand resources

21\. Redundancy: The practice of having multiple copies of data in different locations to avoid a single point of failure

22\. Region: A group of zones

23\. Repository: A centralized place to store, download, and share data

24\. Resiliency: The ability to prepare for, respond to, and recover from disruptions

25\. Single-tenant environment: An environment in which cloud infrastructure and resources are dedicated to a single user

26\. Structured data: Data organized in a certain format, like rows and columns

27\. Unstructured data: Data that is not organized in any easily identifiable way

28\. Virtualization: Technology that creates a virtual version of physical infrastructure, such as servers, storage, and networks

29\. Zone: The collective number of data centers in an area
