## Knowledge Check

### 1. What are two advantages of packaging software in containers? Select two answers.

☑ a. Containers enable users to run software quickly from one computing environment to another.

☐ b. Containers are easy to modify during their lifetimes.

☐ c. Containers combine developers and operations teams’ responsibilities.

☑ d. Containers use less memory and fewer resources.

☐ e. Containers include software and operating systems.

Answer:
- Packaging software in containers allows for portability, meaning it enables users to quickly run software applications from one computing environment to another. This also uses less memory and fewer resources, because the operating system itself is not included in the container.
- Packaging software in a container uses less memory and fewer resources, because the operating system itself is not included in the container. This also allows for portability, meaning it enables users to quickly run software applications from one computing environment to another.

### 2. In the cloud, what is the term for computation performed by a physical computer in a remote environment?

a. Networks

b. Data storage

c. An instance

d. Compute ☑

Answer:
- Computation performed by a physical computer in a remote environment is called compute. For example, memory, CPU, and storage are all compute components.

### 3. What is virtualization?

a. Technology that ensures that information in one virtual machine is not visible to others.

b. Technology that enables organizations to store digital data off-site.

c. Technology that works as an abstraction layer between the physical computer and the virtual machine.

d. Technology that creates a virtual version of physical infrastructure. ☑

Answer:
- Virtualization technology creates a virtual version of physical infrastructure, like servers, storage, and networks. These virtual machines, or VMs then simulate a physical computer.

### 4. As a cloud security analyst, you have been hired to assist with a company’s digital transformation. The company’s management team has informed you that security is their highest priority. Based on this information, what type of hypervisor should the company choose and why?

a. A virtual machine, because it runs an application over the computer’s existing operating system.

b. Type 2, because it never interacts with the operating system.

c. An operating system, because it can be used to test code.

d. Type 1, because it replaces the operating system of the underlying computer. ☑

Answer:
- The company should choose Type 1, because it replaces the operating system of the underlying computer, making it more secure. Type 1, or bare metal hypervisors interact with the underlying computer’s components directly; they do not run inside of an operating system. Having this direct access makes Type 1 more streamlined and secure.
