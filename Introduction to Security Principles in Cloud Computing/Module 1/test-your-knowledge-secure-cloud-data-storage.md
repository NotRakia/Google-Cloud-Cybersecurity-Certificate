# Knowledge Check

## 1. What data type includes names, addresses, credit card numbers, and dates?

a. Structured data

b. Unstructured data

c. Repositories

d. Redundancy

**Correct Answer:** a. Structured data

**Explanation:**

Structured data is organized in a certain format, like rows and columns, and stored in a structured database. Examples of structured data include names, addresses, credit card numbers, and dates. Because it is stored in a structured format, structured data is easy to query and search for.

## 2. A small independent book publisher considers moving its data storage to the cloud. What are two potential benefits of this change? Select two answers.

a. The publisher’s data will only be stored in one location.

b. The publisher will be able to store more data.

c. The publisher will save money.

d. The publisher will maintain the infrastructure needed to host the data.

e. The publisher will be able to pre-buy data in case it needs more than expected.

**Correct Answers:** b. The publisher will be able to store more data. and c. The publisher will save money.

**Explanation:**

When an organization needs to store more data, they can adjust their use of the cloud accordingly without the need to buy, install, organize, and manage new physical devices. Cloud data storage allows small organizations to store amounts of data they would not have the resources to store on their own. This will help them save money.

## 3. A team of developers is using a centralized place to store, download, and share data. What is this central location called?

a. Failure domain

b. A repository

c. Block storage

d. A structured database

**Correct Answer:** b. A repository

**Explanation:**

Developers rely on repositories as a centralized place to store, download, and share data. Data repositories commonly use file storage.

## 4. A music recording studio wants to store and organize a large amount of unstructured data in the form of audio files. Which type of cloud storage should they choose?

a. Buckets

b. File storage

c. Redundancy

d. Uptime

**Correct Answer:** a. Buckets

**Explanation:**

A bucket is a virtual container that holds objects and can be used to store and organize large amounts of unstructured data, such as audio files. Buckets can be public, meaning that anyone can access the objects inside, or private, so only certain people have access.
